# AI生成を取り入れた制作ワークフロー

EditFlow の既存の工程（取り込み → グレーディング → 仮編集 → 原稿 → ナレーション → 本編集 → 修正）に、AI生成の工程を差し込む場合の流れです。生成は Higgsfield の MCP 経由で行う前提です。

## 1. 流れ

```
構成・原稿 (SC)
  └─► AIカット設計 (AP) ……… 必要なカットを洗い出し、モデルを選んでプロンプトを書く。get_cost で費用を見積もる
        └─► AI生成・選別 (AG) … 試作 → 選別 → 本番生成
              └─► AI素材の仕上げ (AF) … 照合（実物の写真と）、アップスケール、フレームレートの変換、色合わせ、ロゴ・文字の重ね
                    └─► 仮編集 (RC) → 本編集 (FC) → 修正 (RV)
```

- AP（設計）は原稿のあとに行います。ナレーションの尺が決まると、各カットに必要な秒数が決まるためです。
- AG は「試作 → 本番」の2段階にします。安いモデルや低い解像度（`veo3_1_lite`、`seedance_2_0_mini`、Seedance 2.5 の `draft`）で構図と動きを決めてから、本番のモデルで生成します。
- 生成（クレジットを使う操作）は、費用を見積もって承認を取ってから行います。
- AF を飛ばさないこと。AI生成の素材は 24fps で出てくることが多く（MiniMax H3 は 24fps ✅）、放送用の本編（29.97p）と混ぜるとガタつきが目立ちます。

## 2. 音の流れ

| 音の種類 | 作り方 |
|---|---|
| 効果音・環境音 | 動画のモデルに作らせてよい |
| 日本語の台詞・ナレーション | `elevenlabs_v4` で作る。1句3テイク以上を作り、耳で選ぶ。数と助数詞は仮名で書く。伸縮させない |
| 会話シーン | 台詞を1行ずつ音声にして、`seedance_2_5` の `audio_references` で渡す |
| BGM（曲） | Higgsfield では作れない。支給か、使用許諾のある音源を編集で入れる |

尺が合わないときは、音を伸び縮みさせずに、原稿か絵の尺を直します。

## 3. 工程の目安時間

`DEFAULT_STEP_LIBRARY` に追加する場合の初期値の案です。

| code | 日本語 | English | 目安(h) | 根拠 |
|---|---|---|---|---|
| AP | AIカット設計 | AI Shot Planning | 1 | 5〜10カット分のプロンプト作成と見積もり |
| AG | AI生成・選別 | AI Generation | 2 | 1カットあたり複数回の生成と、待ち時間込み |
| AF | AI素材仕上げ | AI Finishing | 1 | 照合、アップスケール、fps変換、色合わせ |

番組の種類ごとの組み込み方:
- 地域情報番組: 空舞台・情景カットを補う程度なので、AP と AG を各1h
- 文化番組: 再現・イメージカットを使うなら AP 1h、AG 3h
- CM・ショート: 主役がAI映像になる場合、AP 2h、AG 4h、AF 2h。修正の往復が増えるので RV も多めに見積もる

## 4. モデル選びの目安（Higgsfield）

| やりたいこと | 第一候補 | 次点 |
|---|---|---|
| 動きの試作 | `veo3_1_lite` | `seedance_2_0_mini`、`kling3_0_turbo` |
| 風景・情景の空舞台 | `kling3_0` | `seedance_2_5`、`cinematic_studio_video_4_0` |
| 人物の芝居と台詞 | `seedance_2_5`（台詞は音声を参照で渡す） | `kling3_0` |
| 動きの多いカット、1回でマルチショット | `kling3_0`、`kling_o3_image_reference` | `seedance_2_5` |
| 参照（顔・商品・場所）を多く組み合わせる CM | `seedance_2_5` | `minimax_h3` |
| 2K で欲しい | `minimax_h3` | — |
| 写真を動かす | `kling3_0` / `minimax_h3`（start_image） | `veo3_1_lite` |
| 既存の動画の一部を差し替える | `seedance_2_5`（`video_edit`） | `kling_video_edit` |
| 既存の広告を別の人物・商品・言語で作り直す | `ad_multiplier`（ワークフロー `ad-multiplier`） | — |
| 参考動画から作り直す | ワークフロー `katana` | — |
| ロゴ・文字・図解 | 生成ではなくコードで作る（クレジット不要で崩れない） | ワークフロー `video-editing` |

MiniMax H3 は start_image と image_references を同時に渡せません（422 エラー。手元で確認）。

## 5. 費用を下げる工夫

- プリビズ（Blender のグレーボックス）で構図とカメラを決めてから生成する（RKJ VIDEO の手法）。
- 試作は短い尺・低い解像度・安いモデルで行う。Seedance 2.5 は 480p の `draft` を作り、良いものだけ 1080p に仕上げられる ✅
- Kling 3.0 は `sound: off` にすると安くなる ✅
- ロゴ・文字・図解はコードで作る。

## 6. 記録しておくもの（再生成のため）

クライアントから「さっきのカット、もう少し明るく」と言われたときに再現できるよう、カットごとに次を記録します。

- プロンプト全文とネガティブプロンプト
- Higgsfield のモデルID、モード（t2v / omni_reference / video_edit など）、パラメータ
- 参照素材のIDと、それぞれの役割
- 採用したテイク（ジョブID）と、ファイルの保存先
- 照合の結果（実物の写真と比べて合っていたか）
- 権利メモ（商用利用の可否、クレジット表記の要否、「AI生成」表記の要否）

この記録をアプリで管理する案は [05-editflow-integration.md](05-editflow-integration.md) にあります。
