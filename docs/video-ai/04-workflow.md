# AI生成を取り入れた制作ワークフロー

EditFlow の既存の工程（取り込み → グレーディング → 仮編集 → 原稿 → ナレーション → 本編集 → 修正）に、AI生成の工程を差し込む場合の流れです。

## 1. 流れ

```
構成・原稿 (SC)
  └─► AIカット設計 (AP) ……… 必要なカットを洗い出し、モデルを選んでプロンプトを書く
        └─► AI生成・選別 (AG) … 試作 → 選別 → 本番生成。1カットにつき3〜6回の生成が目安
              └─► AI素材の仕上げ (AF) … アップスケール、フレームレートの変換、色合わせ、整音
                    └─► 仮編集 (RC) → 本編集 (FC) → 修正 (RV)
```

- **AP（設計）は原稿のあと。** ナレーションの尺が決まると、各カットに必要な秒数が決まるためです。
- **AG は「試作 → 本番」の2段階。** 安いモデル（Fast 版、低解像度）で構図と動きを決めてから、高品質版で生成します。
- **AF を飛ばさない。** AI生成の素材は 24fps や 720p で出てくることが多く、放送用の本編（29.97p / 1080p）と混ぜるとガタつきが目立ちます。

## 2. 工程の目安時間

`DEFAULT_STEP_LIBRARY` に追加する場合の初期値の案です。

| code | 日本語 | English | 目安(h) | 根拠 |
|---|---|---|---|---|
| AP | AIカット設計 | AI Shot Planning | 1 | 5〜10カット分のプロンプト作成 |
| AG | AI生成・選別 | AI Generation | 2 | 1カットあたり3〜6回生成し、待ち時間込み |
| AF | AI素材仕上げ | AI Finishing | 1 | アップスケール、fps変換、色合わせ |

番組の種類ごとの組み込み方:
- **地域情報番組**: 空舞台・情景カットを補う程度なので、AP と AG を各1h
- **文化番組**: 再現・イメージカットを使うなら AP 1h、AG 3h
- **CM・ショート**: 主役がAI映像になる場合、AP 2h、AG 4h、AF 2h。修正の往復が増えるので RV も多めに見積もる

## 3. モデル選びの目安

| やりたいこと | 第一候補 | 次点 |
|---|---|---|
| 風景・情景の空舞台 | Veo 3.1 / Gemini Omni Flash | Kling 3.0 |
| 人物の芝居と台詞 | Sora 2 | Kling 3.0 |
| 激しい動き、スポーツ風 | Kling 3.0 | Seedance 2.0 |
| 写真や静止画を動かす | Runway Gen-4.5 | Veo 3.1（最初のフレーム指定） |
| 既存の動画の一部を差し替える | Seedance 2.0 / 2.5 | Veo 3.1 の Edit |
| 素材を外に出せない案件 | Wan 2.7（ローカル） | — |

## 4. 記録しておくもの（再生成のため）

クライアントから「さっきのカット、もう少し明るく」と言われたときに再現できるよう、カットごとに次を記録します。

- プロンプト全文とネガティブプロンプト
- モデル名とバージョン、モード（T2V / I2V / 参照 / 編集）
- シード、アスペクト比、解像度、秒数
- 参照素材のファイル名
- 採用したテイクの番号と、ファイルの保存先
- 権利メモ（商用利用の可否、クレジット表記の要否、「AI生成」表記の要否）

この記録をアプリで管理する案は [05-editflow-integration.md](05-editflow-integration.md) にあります。
