# 確かめていないことの一覧

生成で試さないと分からないものをまとめました。試すのは手元で、費用を `get_cost` で見積もり、承認を取ってからにします。安く試すため、どれも最短の尺・低い解像度・安いモデルから始めます。

結果が出たら、「結果」の欄に日付と結論を書き、該当する資料（01〜06）の印を 🔧（手元で確認）に直してください。

## カメラの指示が効くか

| C5 | 画角を度数で書く指示が効くか | `seedance_2_5` 480p `draft` | |
