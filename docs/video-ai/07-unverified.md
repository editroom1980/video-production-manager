# 確かめていないことの一覧

生成で試さないと分からないものをまとめました。試すのは手元で、費用を `get_cost` で見積もり、承認を取ってからにします。安く試すため、どれも最短の尺・低い解像度・安いモデルから始めます。

結果が出たら、「結果」の欄に日付と結論を書き、該当する資料（01〜06）の印を 🔧（手元で確認）に直してください。

## カメラの指示が効くか

| 番号 | 確かめること | 試し方 | 結果 |
|---|---|---|---|
| C1 | `whip pan` が効くか | `kling3_0` std・3秒・`sound: off`、`seedance_2_0_mini` 480p・4秒で同じ指示 | |
| C2 | `rack focus`（フォーカス送り）が効くか | 同上。手前と奥に被写体を置く | |

| C5 | 画角を度数で書く指示が効くか | `seedance_2_5` 480p `draft` | |
| C6 | 画面の向き（右から左）がカットをまたいで保たれるか | `seedance_2_5` draft、3区切り | |
