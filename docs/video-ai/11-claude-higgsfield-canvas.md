# Topview Canvas と Renoise AI の使い方を、Claude と Higgsfield で行う

出典: YouTube「【2026年最新版】Topview Canvasを使った最新Seedance2.5の活用5選と完全自動化ワークフローを解説します」（チャンネル「動画編集の中の人」、2026-09-03 公開、12分40秒、Topview の紹介リンクつき） https://www.youtube.com/watch?v=ze9HHzP3a6s 。依頼者が文字起こしを貼ったもの（2026-10-23）。
Higgsfield 側の機能は、2026-10-23 に `models_explore` / `get_workflow_instructions` / `get_cost` で確かめた（✅）。

## 0. 共通の決まり（どの使い方でも）

1. 生成（クレジットを使う操作）は、費用を見積もって人が承認してから。手元では VISIONREEL の承認待ち（`visionreel_request_generation` などの道具）に置き、Higgsfield を直接叩かない。VISIONREEL が使えない場所では、`get_cost: true` の見積もりを示して承認を取る
2. 当たりは安いモデルで、本番だけ高いモデルで（動画の「共通テクニック1」）

   | 段 | Higgsfield のモデル | 費用の目安（2026-10-23 の `get_cost`） |
   |---|---|---|
   | 当たり（構図と動き） | `seedance_2_0_mini` 4秒 480p | 2 |
   | 当たり（参照が多い・2K の質感） | `minimax_h3` 4秒 | 8 |
   | 下書き（本番と同じモデル） | `seedance_2_5` 5秒 480p `draft: true` | 15 |
   | 本番 | 下書きの `draft_job_id` で `seedance_2_5` を 1080p に仕上げる | `get_cost` で確認 |

   Seedance 2.5 の下書きは、7日以内なら同じジョブを 1080p に仕上げられる ✅。当たりを Mini で作った場合は、本番で絵が変わることがある（07 の M1）
3. 生成の前に必ず費用を見る（動画の「共通テクニック2」）。`get_cost: true` は、ジョブを送らずに費用だけを返す ✅
4. うまくいった流れは、スキルとして保存する（§2 ⑤）
5. 作る前に聞く（Renoise の回で紹介されていた「エージェントのヒアリング」の代わり）。依頼が短いときは、プロンプトを書く前に、足りないことを一度だけまとめて聞く。聞くのは次のうち決まっていないものだけ:
   - 誰に何を伝えるか（一言）、尺、縦横、媒体
   - 本数とカット数、テンポ（曲があれば BPM）
   - 使う素材（人物・商品の写真、曲、声）と、その権利
   - 参考の動画（あれば。構図とテンポだけを読み取り、そのまま真似はしない）
   - 予算（クレジットの上限）
   聞いたあと、カットの組み立て（構図、カメラ、光、動き、音）と費用の見積もりを表で示し、承認を取ってから生成する。完成した1本が出てくるわけではなく、出てくるのはカットと素材で、仕上げの編集と最後の確認は人が行う

## 2. 使い方ごとの手順

### ① 商品 CM の複数パターン（`hf-variants`）
1. 商品の写真（実物）と、伝えたいことを受け取る。写真は参照に使い、出た絵は写真と照合する（規則9b）
2. Claude が、変える軸を決めて N 案を出す。軸の例: フック（最初の2秒）、広告の形式（visionreel-提案.md の2章、09 の7ジャンル）、相手、トーン、縦横
3. 案ごとにプロンプトを書く（`video-prompt` スキルの決まりで。1本ずつ単独で読めるように）
4. 当たりを安く作る: `seedance_2_0_mini` 4秒 480p（1本 2）を N 本。合計を `get_cost` で示して承認
5. 良い案だけ本番: `seedance_2_5` の下書き → 1080p
6. 既にある広告から作るなら Ad Multiplier: 冒頭だけ（4〜15秒）・最後の呼びかけだけ（4〜5秒）の作り直し、人物や言語を変えた作り直し（Pro プラン以上）✅
7. バナーも要るなら Ads Studio（商品の URL か写真から、複数サイズの静止画広告）✅

### ② モーショングラフィックス（`hf-motion`）
1. 文字・ロゴ・数字・図解は生成しない。コードで作る（手元の code-motion。0クレジット）か、Higgsfield の編集ワークフロー（Higgsedit。文字、図形、キーフレーム、トランジション、2.5D カメラ）✅
2. 動きのある背景や質感だけを生成する:
   - Marketing Studio の `marketing_studio_v2_video`、`type: 2d_motion` か `hypermotion`（5〜15秒、1回に1〜4本、5秒で 29.8）✅。テンプレートは `get_presets`（`source: marketing_studio`、`category: motion`）で選ぶ
   - または `seedance_2_5` / `minimax_h3` で文字なしの背景を作る（Topview の動画でも、モーショングラフィックスに MiniMax H3 を挙げていた ⚠️）
3. 秒単位で動きの区切り（色が変わる、図形が弾ける）を決め、色は3色（メイン・アクセント・背景）に絞る（09 ⑤）
4. 文字を、区切りの時刻に合わせてコードで重ねる。サイズ違いはリフレーム（`reframe`）✅ かコードの書き出し設定で

### ③ 脚本から AI 映画（`hf-script-to-film`）
1. あらすじか脚本の書きかけを受け取る。Claude が台本の形に整える（場面、台詞、秒数の目安）
2. 場面ごとにショット一覧を作る（`visual-video` の role-modes.md と dramaturgy.md の型。ショットの仕事・最後の絵を決める）
3. 人物の設定画を作る（Higgsfield の `character-sheet` ワークフロー、または `visual-image`。三面図は参照に使い、開始の画像にはしない）
4. 場所の画像、各ショットの元になる画像を作り、ここで承認を取る（09 の5つの工程）
5. 声と曲を先に決める（台詞は ElevenLabs v4、曲は支給か許諾済み）
6. ショットごとに動画にする。人物が続く場面は Seedance 2.5 の参照で、1本で作る長さと分ける長さを決める（06 §6 の3）
7. つなぐ（手元の編集ソフトか、Higgsfield の `video-montage` ワークフロー）
- ナレーションが主の説明動画や物語動画なら、Higgsfield の `faceless-video` ワークフローも使える ✅

### ④ 一部だけ直す（`hf-partial-fix`）
1. 崩れた所を見つける: 完成動画から十数コマを切り出して並べる（10 §3）。崩れている秒数（例: 3.0〜5.0秒の手）を決める
2. 直す区間を切り出す: ffmpeg で、崩れた区間の前後に余白を足して切り出す。Seedance 2.5 は4秒以上なので、区間は4秒以上にする ✅（`seedance_2_5` は4〜30秒）
3. 直す:
   - `seedance_2_5` の `mode: video_edit`（料金は渡した動画の長さぶん ✅）。プロンプトは「@Video 1 の、{直す所} だけを {直したい形} にし、ほかはそのまま」と、元の動画を直接指して書く（Runway の Seedance ガイドの書き方）
   - または `kling_video_edit`（Kling 3.0 Omni Edit。文章の指示と参照画像で直す）✅
4. 元の動画に戻す: ffmpeg で、直した区間を差し込む。つなぎ目は動きの途中にし、数フレームの重ねで目立たなくする
5. 切り出したコマで、直った所と、つなぎ目を確かめる
- 費用の考え方: 全体を作り直すより、直す区間の長さぶんで済む。区間を短くするほど安い

### ⑤ うまくいった流れをスキルにする（`workflow-to-skill`）
1. うまくいった1本の流れを、Claude に振り返らせる（使ったモデルと設定、参照素材とその役割、プロンプト、何回目で通ったか、費用）
2. 迷った場面と、そこで選んだものを書き出す（09 §4.5: これが無いと自動化で止まる・質が落ちる）
3. `.claude/skills/<名前>/SKILL.md` に、決まった形で保存する（`workflow-to-skill` スキルの雛形）
4. 次の案件で、商品や人物を差し替えて使う。うまくいかなかった所は、スキルに書き足す

## 3. 料金の比べ方（Topview）
- Topview の動画では、Seedance 2.5 の 720p が1秒あたり約19円、10秒で約190円と紹介されていた ⚠️
- Higgsfield では、`seedance_2_5` の 5秒 720p が 35 クレジット（1秒あたり 7 クレジット）✅。クレジットの円換算はプランで変わるので、ここでは書かない。比べるときは、手元のプランの1クレジットの値段で換算する

## 4. Renoise AI の5つの使い方を、Claude と Higgsfield で行う

出典: YouTube「Renoise AI × Seedance 2.5 の活用法5選」（チャンネル「動画編集の中の人」、2026-09-12 公開、Renoise AI 提供） https://www.youtube.com/watch?v=Vlg-OcEsBOk 。依頼者が文字起こしを貼ったもの（2026-10-23）。Renoise AI は、動画・画像・音声の生成を1つの画面でまとめ、23種類のモデルを1つの契約で切り替えて使えるサービス、と紹介されていた ⚠️。

### 4-1. 対応表

| Renoise AI の機能 | Claude と Higgsfield での代わり | スキル |
|---|---|---|
| 1つの画面で動画・画像・音声を作る | Claude Code ＋ Higgsfield の MCP。Higgsfield も動画・画像・音声（ElevenLabs v4）のモデルを1つの契約で切り替えられる ✅ | — |
| エージェントが足りないことを聞いて、カットを組み立てる | §0 の5（作る前に聞く）。各スキルの最初の手順 | すべて |
| 実行前にプレビューと費用を出し、承認するまで課金しない | `get_cost: true` の見積もりと承認。手元では VISIONREEL の承認待ち | すべて |
| ① 静止画と曲からアニメ MV | 人物の画像と曲を受け取り、テンポとカット数を決め、安く当たりを作り、崩れたカットだけ直し、前のカットの最後のコマを次のカットの開始の画像に渡す | `hf-anime-mv` |
| ② 方向の違う広告を複数（スタジオ風・価格訴求の SNS 広告・使う場面）、縦型にも | `hf-variants` の「3方向」の型 | `hf-variants` |
| ③ シネマティックな映像。同じ場面を2つのモデルで作り比べる | 同じプロンプトと同じ参照で2〜3モデルを安い設定で作り、表で比べる | `hf-model-compare` |
| ④ 搭載モデルの比較と、用途に合うモデルの見つけ方 | 同上。結果を 02 と 04 §4 に書き戻す | `hf-model-compare` |
| ⑤ Claude Code と連携して、決まった形の動画を繰り返し作る（フォルダごとの処理、名前の付け直し、振り分け） | 案件の指示書（一覧表）を読み、生成の一覧を作って一括で承認を取り、終わったら決まった名前で保存し、フォルダに振り分ける | `hf-batch` |

### 4-2. ① 静止画と曲からアニメ MV（`hf-anime-mv`）
動画の例は、人物1人が曲に合わせて動く15秒のアニメ MV。
1. 素材を受け取る: 人物の元になる画像（できれば三面図も）と、使う曲。曲は支給か許諾済みのものに限る（BGM は生成しない）
2. 聞く（§0 の5）: 曲のどの区間か（秒）、BPM、カット数、各カットの動き、縦横。BPM が分からなければ、曲を聞いて決めるか、手元で測る
3. カットの長さを拍で決める: 1拍は 60÷BPM 秒。切り替えを小節の頭に置く。Seedance 2.5 は4秒以上なので、短いカットは4秒で作って編集で切る
4. 人物を固定する: 人物の画像を参照（`image_references`）に入れる。何度も使う人物なら、Higgsfield の要素（`manage_reference_elements` で作り、プロンプトに `<<<要素のID>>>` と書く）にする ✅。三面図は参照に使い、開始の画像にはしない
5. 費用を見る: カットごとに `get_cost`、合計を示して承認
6. 安く当たりを作る: `seedance_2_0_mini` 4秒 480p（1本 2）。動きと構図を見る
7. 本番: 通ったカットだけ `seedance_2_5` の下書き → 1080p。音は `generate_audio: false` にして、編集で元の曲を当てる
8. 前のカットの最後のコマを、次のカットの開始の画像にする（顔と衣装を揃えるため）:
   - ffmpeg で最後のコマを書き出す（`ffmpeg -sseof -0.1 -i cut01.mp4 -frames:v 1 -q:v 2 cut01_last.png`）→ `media_upload` → 次のカットの `start_image` に渡す
   - Seedance 2.5 は `start_image` と `image_references` を同時に渡せる。MiniMax H3 は渡せない（422）ので、この流れでは使わない
   - 続けて動くなら、Seedance 2.5 の `video_extension`（`extension_mode: forward`）で前のカットを延ばす手もある ✅
9. 崩れたカットだけ直す: 作り直すか、`hf-partial-fix` で区間だけ直す
10. 編集で曲に合わせてつなぎ、十数コマを切り出して検品する（10 §3）

### 4-3. ② 方向の違う広告を複数（`hf-variants`）
- 動画で紹介されていた3方向 ⚠️: スタジオで撮ったような商品映像／価格と機能を前に出した SNS 広告／実際に使う場面を見せる映像。同じ商品写真から3本を作り、縦型（9:16）にも出して A/B テストに使う
- 手順は §2 ① と同じ。案を出すときに、この3方向を最初の候補として示す
- 注意（動画でも挙げていた）: 商品のロゴと文字が正しいかを必ず目で確かめる（規則9b）。仕上げの編集と最後の確認は人が行う

### 4-4. ③④ 同じ場面をモデルで作り比べる（`hf-model-compare`）
1. 比べる場面を1つ決め、プロンプトを1本書く。モデルごとの書き方のくせ（02）に合わせて言い回しだけ直し、中身は変えない
2. 候補を2〜3つ選ぶ。動画で挙げていた組み合わせ ⚠️: アニメと一般の AI 動画は Seedance 2.5、モーショングラフィックスは MiniMax H3。動きの多いカットと静かなカットで向くモデルが違う、とも言っていた
3. 安い設定で揃えて作る（例: 5秒、480p〜720p）。各モデルの `get_cost` を並べて、合計の承認を取る。2026-10-23 の目安: `seedance_2_5` 5秒 480p 下書き 15、`kling4_0` 10秒 720p 5、`kling3_0` 10秒 17.5、`minimax_h3` 4秒 8
4. 表で比べる: 動きの滑らかさ、構図、人物の安定、指示への従い方、文字・ロゴ、費用。切り出したコマを並べて見る
5. 結果を 07（M3 など）に書き、決まったことを 02 と 04 §4 のモデル選びに書き戻す。気になった所だけを直して作り直す（全部はやり直さない）

### 4-5. ⑤ 決まった形の動画を繰り返し作る（`hf-batch`）
- Renoise の回での役割分け ⚠️: 1本を作るときはエージェント、同じ作業を何度も繰り返すときや大きな流れは Claude Code との連携
- Claude と Higgsfield での手順:
  1. 案件の指示書を受け取る（1行が1本の表。商品・人物・縦横・秒数・モデル・プロンプトの元）。無ければ Claude が作り、確かめてもらう
  2. 生成の一覧を作り、各行の `get_cost` と合計を示して、まとめて承認を取る。手元では VISIONREEL の承認待ちに1行ずつ置く
  3. 承認のあと、生成のまとめ投入（`generate_video_batch`、1回に2〜12本）→ `jobs_wait` で待つ
  4. 終わったものを保存し、決まった名前に付け直す（例: `{案件}_{カット番号}_{モデル}_{秒数}s_{テイク}.mp4`）。フォルダに振り分ける（手元は VISIONREEL の `素材/`、Higgsfield 側は `create_folder` のフォルダ）
  5. 各行の記録（04 §7）を残す: プロンプト、モデルと設定、参照、ジョブ ID、保存先、費用
- 注意（動画でも挙げていた）: 最後の確認と仕上げは人が行う。回しすぎに注意（承認した合計を超えない）

### 4-6. 費用の考え方
- Renoise の料金は、動画では「1つのプランで23種類」とだけ紹介されていて、金額は出ていなかった ❔
- Higgsfield は、1つの契約のクレジットで各モデルを使う ✅。比べるときは、手元のプランの1クレジットの値段で換算する（§3）
