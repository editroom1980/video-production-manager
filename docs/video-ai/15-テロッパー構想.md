# テロッパー（FCP 用のテロップ作成の拡張）を作れるか（2026-10-24）

依頼者の問い: 「テロッパー」という拡張を作り、Claude と Higgsfield と連携して、FCP で編集中の動画の雰囲気に合わせた装飾入りのテロップ、画面に合う文字のデザイン、文字の下に敷く座布団の画像を作れるか。

根拠: ✅ Apple の資料か Higgsfield の MCP で確かめた（2026-10-24）／ ❔ 未確認・推測。FCP の拡張の全体は 14-finalcut-plugin.md。

## 結論
作れる。ただし、次の分け方にするのが前提になる。
- 文字そのもの: 画像として生成させない。FCP のタイトル（Motion のテンプレート）で、書体・色・縁取り・影を数値で入れる。日本語の文字を画像モデルに描かせると崩れやすく、直しも効かないため（手元の決まり「文字はコードで」と同じ）
- 座布団と装飾: 単純な形（角丸の帯、グラデーション、線）は Claude が SVG のコードで作る（0クレジット、崩れない）。質感のあるもの（筆のかすれ、紙、和柄、光の粒など）だけを Higgsfield で生成する
- 雰囲気を読む: 編集中の画面の1コマを Claude が見て、色・トーン・置き場所を決める

## 仕組み

```
FCP ──(1) プロジェクトをドラッグ／再生位置──► テロッパーの窓（ワークフロー拡張）
                                              │
                         (2) その時刻の1コマを取り出す（素材のファイルから）
                                              │
                         (3) Claude が絵を見て、デザインを決める（色3つ、書体、座布団の形、置き場所）
                                              │
                ┌─────────────┴──────────────┐
         (4a) 座布団: SVG で作る（0 cr）     (4b) 質感: Higgsfield で生成（承認のあと）→ 背景を抜く
                └─────────────┬──────────────┘
                         (5) FCPXML を作る（座布団の PNG＋タイトル、書体と色の値入り）
                                              │
FCP ◄──(6) 窓からタイムラインへドラッグで置く ─┘
```

各段の根拠:

1. 編集中の内容を受け取る ✅
   - FCP のブラウザからプロジェクトをアプリにドラッグすると、FCP は編集の内容を FCPXML で渡す（各クリップの素材の場所と時刻を含む）（Supporting Drag and Drop to Receive Final Cut Pro Data）
   - ワークフロー拡張は、タイムラインの再生位置を読める（`FCPXTimeline.playheadTime()`）
2. 1コマを取り出す ❔
   - FCPXML の素材の場所と再生位置から、その時刻の素材と中の時刻を計算し、手元で1コマを書き出す（AVFoundation か ffmpeg）。計算は自前で、試作で確かめる
   - 代わりの手: FCP の「現在のフレームを保存」で静止画を書き出し、窓にドラッグする ✅（FCP の機能）。手間は1つ増えるが確実
3. Claude が決める（推測）
   - 決めること: 画面の色から取った3色（文字・縁・座布団）、トーン（ニュース風、バラエティ風、上品、ポップなど）、書体の方向（Mac に入っている書体の一覧から選ぶ）、座布団の形、置き場所（顔・商品・既存の文字を避ける）、安全域（放送・縦型 SNS）
   - 候補を3案出して選ばせる
4. 座布団と装飾を作る
   - SVG のコード（0 cr）: 角丸の帯、二重線、グラデーション、吹き出し。Claude が書いて PNG にする
   - Higgsfield ✅（2026-10-24 の `get_cost`。1枚あたり）:

     | モデル | 向いているもの | 費用 |
     |---|---|---|
     | `gpt_image_2_5` | 一般の画像。質感のある背景 | 0.25 |
     | `nano_banana_pro` | 一般の画像 | 2 |
     | `recraft_v4_1`（`model_type: vector`） | ベクター風の飾り、アイコン。色を10色まで指定、背景色を指定できる | 2.5 |
     | `ideogram_vector` | SVG で出す。既存の画像のベクター化もできる | 5 |

   - 透過: `remove_background` で背景を抜く ✅。ベクターの出力なら、そのまま透過にできる
   - 生成は、これまでと同じく見積もって承認のあと
5. FCP に戻す形 ✅
   - FCPXML の `title`（文字の塊と書式 `text-style`）と、PNG の素材を、上の段（lane）につないだクリップとして書く（FCPXML Reference の Story Elements、title）
   - 拡張の窓からタイムラインにドラッグで置く ✅（Supporting Drag and Drop for Data Sent to Final Cut Pro）
   - 拡張はタイムラインを直接書き換えられないので、置くのは人のドラッグ1回 ✅（14 の C）
6. 動き
   - 入りと出の動きは、Motion のテンプレートの中に作っておく
   - 動く装飾（光の筋、粒）は、コードで透過つきの動画（ProRes 4444）に書き出す（手元の code-motion。0 cr）か、Higgsfield の動画のあと背景を抜く（`sam_3_video` など。費用は `get_cost`）

## 用意するもの
- テロップの Motion テンプレート（数種）: 文字の欄、座布団を差す枠、色・縁・影の値を公開しておく。FCPXML から値を入れられる範囲は ❔（文字と書式は入る。枠の画像を FCPXML から差せるかは試す）
- 書体: Mac に入っていて、商用で使える書体に限る。書体の使用許諾は手元で確かめる
- 拡張: Xcode の Workflow Extension の雛形。中身は VISIONREEL と同じく Node のサーバーにつなぐか、Swift で作る（14 の C と同じ未確認の点あり）

## 段階の案
0. 拡張なしで試す（すぐできる）
   - FCP で「現在のフレームを保存」→ その画像と文言を Claude Code に渡す
   - Claude がデザインを3案出す → SVG の座布団と FCPXML（タイトル＋座布団）を作る
   - FCP で FCPXML を読み込む
   - ここで、Claude のデザインの質と、FCPXML のタイトルで書体・色が狙いどおり入るかを確かめる
1. Motion のテンプレートを整える（テロップの型を3〜5種）
2. ワークフロー拡張にする: 再生位置の1コマを自動で取り、窓の中で案を選び、ドラッグで置く
3. 質感の生成（Higgsfield）と、承認の流れを入れる
4. 同じ番組・案件の中でデザインを揃える: 決めた色・書体・座布団を「案件のテロップの型」として保存し、次から同じ型で作る

## 分からないこと・気をつけること
- 素材のファイルの場所と再生位置からの1コマの計算（速度の変更、複合クリップ、マルチカムがあるとややこしい）❔
- FCPXML から Motion テンプレートの画像の枠に、座布団の画像を差せるか ❔
- 拡張の中で Web の画面が使えるか、ローカルのサーバーにつなげるか ❔（14 の C）
- 実在のロゴや番組のデザインに似せない（10 §5）
- テロップの文言の誤字・数字の確認は人が行う
