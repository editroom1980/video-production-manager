# 毎日の時事・天気の風刺動画を作って TikTok に出す（設計、2026-10-25）

依頼者の希望: その日の時事・天気・話題を調べ、それを風刺する30秒のアーティスティックな動画を作り、毎日 TikTok に投稿する。
根拠: ✅ Higgsfield の MCP で確かめた（2026-10-25）／ ⚠️ 第三者の記事／ ❔ 未確認・推測

## 0. 分かったこと（作る前の前提）
- TikTok への投稿は、Higgsfield の MCP の道具で行える ✅
  - 流れ: `tiktok_connect`（アカウントをつなぐ。初回だけ。依頼者がリンクを開いて許可）→ `tiktok_prepare_publish`（投稿の画面を開く）→ 依頼者が画面で確かめて送る → `tiktok_publish_status`
  - 投稿の最後の「送る」は、人が投稿の画面で押す。Claude が自分で投稿する道具は無い（道具の説明に「tiktok_publish を自分で呼ばない」とある）。投稿の画面は、MCP の画面部品が出る Claude のアプリでしか開けない
  - `DIRECT_POST`（すぐ公開）と `UPLOAD_TO_DRAFT`（TikTok の下書きに保存）が選べる
  - AI 生成の印（`is_aigc`）、公開範囲、コメント・デュエット・ステッチの可否、広告表示を、画面で選ぶ
  - 曲は、TikTok の商用楽曲ライブラリ（許諾済み）から投稿の画面で選べる（`DIRECT_POST` のときだけ）。Higgsfield で曲を作らない手元の決まりと合う
  - 動画の条件: MP4・WebM・MOV、3〜600秒、短い辺が360px 以上、23〜60fps。動画の URL は Higgsfield に置いたものに限る
- 今は TikTok のアカウントがつながっていない（`tiktok_accounts` が空）✅
- 1日1本の費用（30秒、縦 9:16、素材なしの `get_cost`）✅

  | モデル | 設定 | 1本 | 30日 |
  |---|---|---|---|
  | `kling4_0` | 30秒 1080p | 30 | 900 |
  | `wan3_0` | 30秒 720p | 52.5 | 1,575 |
  | `seedance_2_5` | 30秒 480p 下書き | 90 | 2,700 |
  | `seedance_2_5` | 30秒 720p | 210 | 6,300 |

  作り直しが出れば増える。元になる静止画を先に作るなら、1枚 0.25（`gpt_image_2_5`）から

## 1. 1日の流れ

```
朝 6:00（定期実行。生成しない）
  1. 調べる: その日の時事、天気（地域を決める）、話題（出典の URL を残す）
  2. 風刺の安全確認（§2）を通るネタを3つに絞る
  3. 1つを選び、30秒の構成（3〜6カット）、絵の決まり（画風・色）、プロンプトを書く
  4. 見積もる（get_cost）。報告を残して、依頼者に知らせる
        ↓
依頼者が確かめる（スマホの Claude アプリで「OK」か「2番で」）……1回目の確認
        ↓
  5. 生成（承認した金額の範囲で）→ 検品（十数コマを切り出す。実在の人に似ていないか、文字の崩れ）
  6. 必要なら短い文字を重ねる（コードで。生成させない）
  7. 投稿の画面を開く（tiktok_prepare_publish。AI 生成の印は「はい」、説明文とハッシュタグを入れておく）
        ↓
依頼者が動画を見て、曲を選んで送る……2回目の確認
```

- 依頼者の手間は1日2回、合わせて数分の見込み（推測）
- 1回目の確認を省きたい場合は、「1日あたり〇クレジットまでは確認なしで生成してよい」という常設の承認を、依頼者がはっきり決める必要がある。今の決まり（生成の前に必ず OK）を変えることになるので、依頼者が決める
- 2回目（投稿）は、道具の作りの上で人が押す。これは残る

## 2. 風刺の安全確認（毎回ネタを選ぶ前に通す）
風刺は、立場の強いもの・仕組み・世の中の空気を笑う。弱い立場の人を笑わない。
- 実在の人物に似せない（政治家・有名人を含む）。人は出さず、動物・物・天気・抽象的な形などの寓話にする
  - TikTok は、公人を描いた AI 生成物でも、政治的・商業的な支持に使うものを認めていない。私人の似姿は一切認めていない ⚠️（ https://www.petapixel.com/2023/03/21/tiktoks-new-guidelines-say-ai-generated-media-must-be-disclosed 、 https://musicbusinessworldwide.com/tiktok-says-its-testing-automatic-ai-content-detection-as-it-rolls-out-new-ai-generated-label-for-creators ）
  - 日本では、似せた顔や声はパブリシティ権の問題になり得る（10 §5）。名誉毀損は風刺でも成り立ち得る ❔（一般論。案件では専門家に）
- 実在の会社のロゴ・商品を笑いものにしない
- 死傷者の出た災害・事件・事故、被害者、病気、宗教、民族、性、障害を笑いの対象にしない。その日の大きな災害のニュースがあれば、その日は天気や季節の話題に切り替える
- 本当の出来事と見間違える映像にしない（写実的なニュース映像風にしない）。画風を絵画・人形・切り絵などにして、作り物だと一目で分かるようにする。AI 生成の印は必ず付ける
- 事実の部分（数字、日付、出来事）は出典で確かめ、説明文に出典の要点を書く
- 選挙の期間中は、候補者・政党を扱わない（推測による安全側の決まり）
- 迷うネタは選ばない。3つとも危うければ、天気・季節・暮らしのネタにする

## 3. 絵と音の決まり
- 縦 9:16、30秒。1本の生成で作るなら `kling4_0`（安い）か `wan3_0`。構成を細かく割りたいなら、10秒×3本でつなぐ
- 毎日同じ「画風の決まり」（色3つ、質感、カメラの癖）を使い、アカウントの見た目を揃える。最初に依頼者と決めて、スキルに書いておく
- 文字は生成させない。入れるなら短い一言を、コードで重ねる
- 曲は生成しない（`No music`）。効果音・環境音は生成してよい。曲は投稿の画面で TikTok の許諾済みの曲から選ぶ

## 4. 作るもの
- スキル `daily-satire-tiktok`: 毎朝の調べもの、安全確認、構成、見積もり、報告、承認後の生成・検品・投稿の画面まで
- 定期実行: 毎朝6時（時刻は依頼者が決める）。クラウドの定期実行で、Higgsfield と Web 検索を使う。生成はしない

## 5. 始める前に決めること・すること
1. 依頼者が決めること
   - 天気の地域（例: 姫路）
   - 1回目の確認を残すか、1日の上限つきの常設の承認にするか
   - モデルと1日の上限（例: `kling4_0` で 30〜60）
   - 画風の決まり
   - 投稿はすぐ公開か、下書きか
   - 投稿する時刻
2. TikTok のアカウントを Higgsfield につなぐ（`tiktok_connect` のリンクを依頼者が開いて許可）
3. 生成なしで1回試す（07 の D1: 定期実行で Higgsfield が使えるか）
4. 最初の1週間は「下書き」に保存する形で回し、質と安全確認の効き方を見てから公開に切り替える
