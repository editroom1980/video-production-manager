# 指輪 | YUBIWA の「AI監督と、Seedance 2.5で映画をつくる」から、AI 映画の工程

出典: YouTube「AI監督と、Seedance 2.5で映画をつくる【TopViewのAI映画スタジオ】」（チャンネル「指輪 | YUBIWA」@YubiwaUniverse、2026-09-29 公開、6分28秒、TopView の提供つき、約5.2万回再生） https://www.youtube.com/watch?v=dSb5WiqLhDk
読み方: Higgsfield の動画解析（`video_analysis_create`、無料、2026-10-26）で、場面ごとの絵と語りを取った。文字起こしではないので、細かい言い回しは違うことがある ⚠️

チャンネルについて: 暗号資産・AI・新しい技術の道具を、実際に使って紹介するチャンネル。提供つきの回が多い。AI 映像の回はほかに、TapNow（2026-10-24）、Pollo AI の広告（07-15）、OiiOii のアニメ（05-23）、Hailuo のホラー映画（05-16）がある。

## 1. 作った作品
- 題材: 大きな産業事故のあとの「もう一つの日本」。人の手を離れた広い土地に、日本建築の要素をもつコンクリートと金属の建物。ゆっくりで重い映画
- 筋: 遺体が見つかった海辺の町に刑事が来る。地元の警察には、都合のいい容疑者がすでにいる
- 絵の特徴: 色を落とした灰・茶・暗い緑。霧、ぬかるみ、錆びた鳥居、着物を着た不気味なロボット、ガスマスクの警官

## 2. 工程（動画で見せた順）
| 段 | すること | 動画での要点 |
|---|---|---|
| 1 | 空のプロジェクトから始める | 何を作るかはまだ決めていない。手元にあったのは Midjourney で作った2枚（錆びた鳥居、古い工場の不気味なロボット） |
| 2 | 世界と筋を決める | 2枚の絵から、世界（産業事故後の日本）と、ゆっくり重い調子と、筋の一行を決める |
| 3 | 人物を作る | AI のエージェントが人物と名前を提案し、相談しながら筋と人物のデザインを詰める。人物ごとの資料（例: 黒田・警視庁の捜査官）に、説明・衣装・参照画像・表情を持たせる |
| 4 | 小道具を作る | 拳銃などの設定画（デザインシート）も作る |
| 5 | 世界カードを作る | 場所ごとの「見た目の決まり」をカードにまとめる（例: 鳥居の立つ海岸、工業地帯と田舎の境）。文章の説明と見本の絵。これがあれば「田舎の場面がほしい」と言うだけで揃った絵が出る |
| 6 | 主人公に一番時間をかける | 主人公を作るのに一番時間がかかった。そのあとはエージェントが画風をつかみ、ほかの人物は楽になった |
| 7 | 筋を場面に分ける | 何を見せるか、どこで間を取るか、緊張をどう変えるかを決める。場面カードに、ショットの説明と設定（720p、16:9 など） |
| 8 | 場面ごとに素材を選ぶ | エージェントが場面に要る人物・場所・小道具を選ぶ。足りなければ作ることを提案する |
| 9 | 構図を 3D で決める | 3D Shot Composer で、灰色のマネキンを仮想の部屋に置き、カメラの角度を決める |
| 10 | 生成する | Seedance 2.5（30秒まで、参照50まで）。カメラはほとんどのカットで固定した。構図と人の動きを見せたかったから（Seedance のカメラワークは好きだが、あえて） |
| 11 | 直す | エージェントが結果を見て、プロンプトの直しを提案する。それでも何度も作り直した。短くうまくいったクリップに足していく方が楽 |
| 12 | 声と効果音 | 声を「Audio Design」で作り、人物の資料に付ける。その声を動画生成の参照に使う。効果音も作れる |
| 13 | つなぐ | タイムラインで切って並べる |

動画の主張: 1つでも崩れると誰も見たくなくなり、ただの雑な AI 動画になる。だから「AI 監督」が要る ⚠️

## 3. Claude と Higgsfield での置き換え
| TopView の機能 | Claude と Higgsfield | 備考 |
|---|---|---|
| Video Agent（AI 監督） | Claude ＋スキル `hf-script-to-film` | 手元ではすでにこの形 |
| 人物の資料（説明・衣装・参照・表情） | 人物ごとの README（例 `characters/haku/README.md`）＋ Higgsfield の要素（`manage_reference_elements`、category `character`）＋設定画（`character-sheet` ワークフロー） | ハクで実際に作った形と同じ |
| 小道具の設定画 | Higgsfield の要素（category `prop`）＋設定画 | 手元では既に例がある（サッカーの球、スパイク） |
| 世界カード | 場所ごとの README（見た目の決まりの英文、色、光、見本の絵）＋ Higgsfield の要素（category `environment`） | 新しく足す型（§4） |
| 場面カード | ショット一覧（`visual-video` の dramaturgy.md の型）。各カットに、見せること・間・緊張の変化を書く | `hf-script-to-film` の手順2 |
| 素材の選び方の提案 | Claude が場面ごとに要る要素を一覧にし、足りないものの作成を（見積もりつきで）提案する | |
| 3D Shot Composer | Higgsfield の 3D Jutsu（`scene_builder_3d_*`。`get_preset_instructions` の `/3d-jutsu` を先に読む）、または手元の Blender のプリビズ | 3D Jutsu は手元ではまだ試していない ❔ |
| Seedance 2.5 で生成 | `seedance_2_5`（30秒まで、参照）。カメラを固定するカットは「static camera」を明記 | |
| 短い成功に足していく | `seedance_2_5` の `video_extension`（`extension_mode: forward`）か、最後のコマを次の開始の画像に | `hf-anime-mv` と同じ |
| Audio Design（声を人物に付ける） | ElevenLabs v4（`create_voice` で声を作り、`elevenlabs_v4` で台詞）→ `audio_references` で動画に渡す | 規則9c のとおり |
| タイムライン | 手元の編集ソフト（FCP）。FCPXML で渡す（14） | |

## 4. 手元に足すこと
1. 世界カード: 場所ごとに、見た目の決まりを1枚にまとめる型を作る。`docs/video-ai/characters/` と同じく、作品ごとに `worlds/<作品>/<場所>/README.md`（見た目の英文、色3つ、光、天気、時代、見本の絵、Higgsfield の要素 ID）
2. 主人公を最初に固める: 主人公の設定画と要素を先に作り、そこで画風を決めてから、ほかの人物・場所を作る（ハクのときと同じ順番。動画でもここに一番時間がかかった）
3. カメラは固定を基本にする: 構図と人の動きを見せる作品では、カメラを固定するカットを多くする。動かすのは意図があるときだけ（01 の「1カット1動作」と合う）
4. 短い成功に足す: 長い1本を何度も作り直すより、短くうまくいったクリップを延ばす・つなぐ
5. 3D で構図を決める: Higgsfield の 3D Jutsu を試す（07 に試験を足す）

## 5. 確かめていないこと
- TopView の Film Studio の各機能の細かい中身（動画の画面で見えた範囲だけ）
