# 指輪 | YUBIWA の「AI監督と、Seedance 2.5で映画をつくる」から、AI 映画の工程

出典: YouTube「AI監督と、Seedance 2.5で映画をつくる【TopViewのAI映画スタジオ】」（チャンネル「指輪 | YUBIWA」@YubiwaUniverse、2026-09-29 公開、6分28秒、TopView の提供つき、約5.2万回再生） https://www.youtube.com/watch?v=dSb5WiqLhDk
読み方: Higgsfield の動画解析（`video_analysis_create`、無料、2026-10-26）で、場面ごとの絵と語りを取った。文字起こしではないので、細かい言い回しは違うことがある ⚠️

チャンネルについて: 暗号資産・AI・新しい技術の道具を、実際に使って紹介するチャンネル。提供つきの回が多い。AI 映像の回はほかに、TapNow（2026-10-24）、Pollo AI の広告（07-15）、OiiOii のアニメ（05-23）、Hailuo のホラー映画（05-16）がある。

## 1. 作った作品
- 題材: 大きな産業事故のあとの「もう一つの日本」。人の手を離れた広い土地に、日本建築の要素をもつコンクリートと金属の建物。ゆっくりで重い映画
- 筋: 遺体が見つかった海辺の町に刑事が来る。地元の警察には、都合のいい容疑者がすでにいる
- 絵の特徴: 色を落とした灰・茶・暗い緑。霧、ぬかるみ、錆びた鳥居、着物を着た不気味なロボット、ガスマスクの警官

## 2. 工程（動画で見せた順）
| 段 | すること | 動画での要点 |
|---|---|---|
| 1 | 空のプロジェクトから始める | 何を作るかはまだ決めていない。手元にあったのは Midjourney で作った2枚（錆びた鳥居、古い工場の不気味なロボット） |
| 2 | 世界と筋を決める | 2枚の絵から、世界（産業事故後の日本）と、ゆっくり重い調子と、筋の一行を決める |
| 3 | 人物を作る | AI のエージェントが人物と名前を提案し、相談しながら筋と人物のデザインを詰める。人物ごとの資料（例: 黒田・警視庁の捜査官）に、説明・衣装・参照画像・表情を持たせる |
| 4 | 小道具を作る | 拳銃などの設定画（デザインシート）も作る |
| 5 | 世界カードを作る | 場所ごとの「見た目の決まり」をカードにまとめる（例: 鳥居の立つ海岸、工業地帯と田舎の境）。文章の説明と見本の絵。これがあれば「田舎の場面がほしい」と言うだけで揃った絵が出る |
| 6 | 主人公に一番時間をかける | 主人公を作るのに一番時間がかかった。そのあとはエージェントが画風をつかみ、ほかの人物は楽になった |
| 7 | 筋を場面に分ける | 何を見せるか、どこで間を取るか、緊張をどう変えるかを決める。場面カードに、ショットの説明と設定（720p、16:9 など） |
| 8 | 場面ごとに素材を選ぶ | エージェントが場面に要る人物・場所・小道具を選ぶ。足りなければ作ることを提案する |
| 9 | 構図を 3D で決める | 3D Shot Composer で、灰色のマネキンを仮想の部屋に置き、カメラの角度を決める |
| 10 | 生成する | Seedance 2.5（30秒まで、参照50まで）。カメラはほとんどのカットで固定した。構図と人の動きを見せたかったから（Seedance のカメラワークは好きだが、あえて） |
| 11 | 直す | エージェントが結果を見て、プロンプトの直しを提案する。それでも何度も作り直した。短くうまくいったクリップに足していく方が楽 |
| 12 | 声と効果音 | 声を「Audio Design」で作り、人物の資料に付ける。その声を動画生成の参照に使う。効果音も作れる |
| 13 | つなぐ | タイムラインで切って並べる |

動画の主張: 1つでも崩れると誰も見たくなくなり、ただの雑な AI 動画になる。だから「AI 監督」が要る ⚠️

## 3. Claude と Higgsfield での置き換え
| TopView の機能 | Claude と Higgsfield | 備考 |
|---|---|---|
| Video Agent（AI 監督） | Claude ＋スキル `hf-script-to-film` | 手元ではすでにこの形 |
| 人物の資料（説明・衣装・参照・表情） | 人物ごとの README（例 `characters/haku/README.md`）＋ Higgsfield の要素（`manage_reference_elements`、category `character`）＋設定画（`character-sheet` ワークフロー） | ハクで実際に作った形と同じ |
| 小道具の設定画 | Higgsfield の要素（category `prop`）＋設定画 | 手元では既に例がある（サッカーの球、スパイク） |
| 世界カード | 場所ごとの README（見た目の決まりの英文、色、光、見本の絵）＋ Higgsfield の要素（category `environment`） | 新しく足す型（§4） |
| 場面カード | ショット一覧（`visual-video` の dramaturgy.md の型）。各カットに、見せること・間・緊張の変化を書く | `hf-script-to-film` の手順2 |
| 素材の選び方の提案 | Claude が場面ごとに要る要素を一覧にし、足りないものの作成を（見積もりつきで）提案する | |
| 3D Shot Composer | Higgsfield の 3D Jutsu（`scene_builder_3d_*`。`get_preset_instructions` の `/3d-jutsu` を先に読む）、または手元の Blender のプリビズ | 3D Jutsu は手元ではまだ試していない ❔ |
| Seedance 2.5 で生成 | `seedance_2_5`（30秒まで、参照）。カメラを固定するカットは「static camera」を明記 | |
| 短い成功に足していく | `seedance_2_5` の `video_extension`（`extension_mode: forward`）か、最後のコマを次の開始の画像に | `hf-anime-mv` と同じ |
| Audio Design（声を人物に付ける） | ElevenLabs v4（`create_voice` で声を作り、`elevenlabs_v4` で台詞）→ `audio_references` で動画に渡す | 規則9c のとおり |
| タイムライン | 手元の編集ソフト（FCP）。FCPXML で渡す（14） | |

## 4. 手元に足すこと
1. 世界カード: 場所ごとに、見た目の決まりを1枚にまとめる型を作る。`docs/video-ai/characters/` と同じく、作品ごとに `worlds/<作品>/<場所>/README.md`（見た目の英文、色3つ、光、天気、時代、見本の絵、Higgsfield の要素 ID）
2. 主人公を最初に固める: 主人公の設定画と要素を先に作り、そこで画風を決めてから、ほかの人物・場所を作る（ハクのときと同じ順番。動画でもここに一番時間がかかった）
3. カメラは固定を基本にする: 構図と人の動きを見せる作品では、カメラを固定するカットを多くする。動かすのは意図があるときだけ（01 の「1カット1動作」と合う）
4. 短い成功に足す: 長い1本を何度も作り直すより、短くうまくいったクリップを延ばす・つなぐ
5. 3D で構図を決める: Higgsfield の 3D Jutsu を試す（07 に試験を足す）

## 5. 確かめていないこと
- TopView の Film Studio の各機能の細かい中身（動画の画面で見えた範囲だけ）
- 動画の最後で「GPT-2.5 が TopView に」と言っていたように読めたが、解析の読み違いの可能性がある ❔
- 料金（Pro は月16ドルから、Ultra は1年無制限と画面に出ていた ⚠️）

# 同じチャンネルのほかの4本（2026-10-26 に Higgsfield の動画解析で読んだ）

## 6. TapNow（hmba4JMZiYY、2026-10-24、8分09秒、全編読めた）
作品: 自作の RPG の世界をゲーム画面風の映像と予告にしたもの（ガスマスクの兵士、斧の女、仮面の敵、黒い泥の村）。
- 困りごと（動画の主張 ⚠️）: 狙ったショットがそのまま出ない。人物の動き、カメラの角度、プロンプトの指示の取りこぼし。作り直すたびにお金がかかる
- 準備に1週間: 世界と人物を作り込んだ
  - 発想は Midjourney（短いプロンプトで幅広く出る）。場所・主人公・敵・ボスの原案をここで出す
  - 決めた案を別のモデルで仕上げる: 場所は Seedream、人物の設定画は GPT Image
  - うまくいった絵を次の生成の参照にして、質感を揃える
  - 細部を別に作る: 敵の仮面の下の顔、場所の建物、武器のデザイン
- エージェントの使い方: キャンバスに全部を並べる。エージェントが大事な情報をキャンバスのメモに残し、ほかのエージェントもそれを読んで背景を分かる。1つのプロジェクトに複数のエージェントを入れて役割を分ける（「seedance-2-5-prompt-copilot」というスキルがあった）
- 画像と文章では足りないとき: 場面の簡単な 3D のブロックアウト（灰色の箱と道とカメラの動き）を動画にして、動画の参照として渡す。場所の画像とやりたいことを送ると、エージェントが約10分で 3D の場面（環境、人物、カメラ、動き）を組む
- 大事な学び（本人の経験 ⚠️）
  - カメラの動きと大きな動きは、動画の参照に任せるのがよい。プロンプトで同じことを細かく書き直すと、ブロックアウトから外れることがある
  - ブロックアウトの余計な細部が本番に出ることがある。だから先に Seedance の下書き（draft）で見て、うまくいったものだけ 1080p に仕上げる。1本あたりは高くつくが、失敗に使うお金は減る
  - Topaz の高解像度化は、Seedance 自身で仕上げるより画質が明らかに落ちた
- 直し方: 気に入っているが1か所だけだめなら、その区間を切り出し、直したい内容を文章・直したコマ・参照で伝える。不要な物を消す、カメラを変えることもできる。うまくいった場面は前にも後ろにも延ばせる（自然につなぐ、動きを合わせる、カメラの動きを続ける）
- 構図を細かく決める: 「Director Desk」で 3D のマネキン・岩・木を置き、カメラと光を決め、その状態から参照の画像を作る
- 変わった形の小道具（散弾銃）がうまく持てない: Tripo で 3D モデルを作り → Daz Studio で手に持たせ → いくつかの角度でスクリーンショット → それをもとに多角度の画像を作り → その画像で動画にした
- 他人の作品のプロンプトと流れを見られるギャラリーがある

## 7. Pollo AI の広告（7Mg9rUYiUrs、2026-07-15、2分52秒、全編読めた。解析では「Apollo AI」と聞こえていた）
- 広告の素材づくりを3段に分ける（本人の整理 ⚠️）
  1. 商品の「顔」: 白背景の素の写真から、ランディングページの一枚目になる主役の絵（AI Product Shot）
  2. 使う場面: 仮想の試着（Virtual Try-on）で、大きさや暮らしの中での見え方を見せる。買う前の不安を減らす
  3. 動き: TikTok・リール・広告の頭に使う短いフック動画（Product Showcase Video）
- 2つの相手を分ける: すでに商品を見ている人には信頼の材料（Commerce Studio）、まだ興味のない人には衝動買いの流れ（Marketing Studio）
- 予測どおりの結果がほしいなら、白背景のきれいな素材を使う。素材は GPT Image 2 か Nano Banana Pro で作れる。ラベルの文字が謎の記号になりにくい
- プリセットだけで、プロンプトを1語も書かずに作った例も見せていた

## 9. Hailuo AI のホラー映画（OkAtrhjy4a0、2026-05-16、9分51秒、全編読めた）
作品: 伊藤潤二の漫画『ファッションモデル』を題材にした短編（90年代の日本のホラーの冷たい空気）。
- 注意: 市販の漫画を原作にしている。手元で同じことをするなら、原作の権利者の許諾が要る（10 §5）
- 作業の順番を先に決めた: 配役（人物作り）→ 要の場面の設計 → 動画 → 音 → 編集
- 人物: 漫画の画面を参照に Nano Banana 2 で、主要人物の正面の素の顔を作った。顔立ち・髪型・年齢は保ち、漫画の誇張だけを実写の顔に近づけた。その顔をもとに、場面ごとの衣装の版を作った
- 敵役: 原作の過剰なグロテスクさはあえて封じ、「人に近いのに決定的に何かがおかしい」怖さを狙った
- 元になる画像: 漫画のコマから、構図・カメラの角度・人物の配置・場面の流れを取った。作品全体のトーンはプロンプトでできるだけ固定し、場面ごとに変えるのは場所・光の入り方・人物の配置・必要な動きだけ
- 参照の役割分け: Hailuo では @ で参照の役割を分けられる。漫画のコマ＝構図と流れ、人物の画像＝顔と衣装
- 一度で決まらない場面: 先に背景を作り、あとから人物を足し、構図を少しずつ詰めた
- そのまま実写にできないコマ: 元の絵の「役割」だけ残し、構図と角度を映画の絵として作り直した
- 同じ場面の別アングル: AnyAngle（元の画像から角度と距離を変えた別カットを作る）。光の調整: Light Studio（構図はそのまま、光の向き・明るさ・調子を変える）
- 動画の段で一番大事なのはテンポ: 静かなカット、長いショット、ゆっくりのカメラ。そうすると、モデルに不自然な動きをさせずに済む
- エージェント: 日本語で場面を説明すると、モデルに合った英語のプロンプトに整える
- モデルの使い分け（本人の経験 ⚠️）
  - 多くの場面の土台: Hailuo 2.3（カメラの理解がよく、表情が安定）
  - 単純な雰囲気のカット: Hailuo 2.3 Fast（大きな作品ではクレジットの消費が大事）
  - 会話と音が要る場面: Veo 3.1（映像と声が一緒に作れる。開始と終了のコマを指定でき、1本の中で角度も変えられる）
  - 会話が少し込み入ると、台詞の順番と動きが崩れやすい。そこは Seedance 2.0 で作り直した（画像・音声・動画の参照をタグで役割分けできる。動画の参照を始まりにすると、同じ声と感情のまま続きを作れる）
- 1回の生成に詰め込まない。1回の生成には分かりやすい動きを1つ
- クリップの長さを動きに合わせる。合っていないと、モデルが動きを遅く・速くして、映像のリズムが崩れる
- 編集で見ていたのは視線の流れ: どこを見せたいか、カットをまたいで動きが自然につながるか、引き → 中 → 寄りに移るタイミング
- 音: 曲より、部屋のノイズや、音がふっと消える瞬間の方が強く効いた（曲は MiniMax Audio で作っていたが、手元の決まりでは曲は生成しない）
- まとめの言葉: AI はもう本格的な映画制作に使える。ただ、最後に映画としてまとめるのは人

## 11. 手元の資料・スキルに取り込んだこと
- `hf-script-to-film` に足した: 3D のブロックアウトを動画の参照にするときは、カメラの動きをプロンプトで書き直さない／クリップの長さを動きに合わせる／1回の生成に動き1つ／先に背景、あとから人物／静かなカット・長いショット・ゆっくりのカメラで不自然な動きを避ける／編集では視線の流れと、引き → 中 → 寄りのタイミング／音は部屋のノイズと無音を使う
- 07 に Y3〜Y5 を足した
