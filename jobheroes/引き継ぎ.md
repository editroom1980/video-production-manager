## アプリのチェックの読み方（`JHDATA:` の中身）
すべて `index.html` の中のデータで読み替えられる。
- `e数字`・`d数字`：必須の予定（`EV` の `key`）。前日・当日
- `p-名前`：体験・場面の「撮り終えた」（`SPOTS` の `id`）
- `f数字-カット`：会社ごとの5カット。数字は `FIRMS` の並び順（0から）、カットは name=会社名 / hand=手元 / face=顔 / smile=笑顔 / q=一問
- `s-e-時刻-番号`・`s-d-時刻-番号`：場面ごとの「撮るカット」（`SHOTS` の `e:時刻`・`d:時刻` の何番目か）
- `m`・`k`・`q`・`g` + 数字：要点タブのチェック（旧「必ず押さえる」・聞くこと・インタビュー・持ち物）
