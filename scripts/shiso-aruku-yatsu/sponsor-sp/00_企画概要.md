## 1. 本数と並び

**30分の番組を、1社につき1本。全部で4本。** どの回も、その1本だけで成立するように作ります。

| 回（案） | 会社 | サブタイトル（案） | ロケ |
|---|---|---|---|
| 1 | 株式会社山弘（ヤマヒロ） | しそう杉の家で、冬なのに裸足になる | **12月1日（火）** たつの・龍野モデルハウス 9:00 → 宍粟・本社（オープニング） |
| 2 | 株式会社川本石材商会 | 160年、石を刻む家 | 未定（お客さんのお墓の場所が分かってから決める。10/28も候補） |
| 3 | お食事処 ドライブインオアシス | ドライブインに、歩いて行く | 未定（未連絡） |
| 4 | 株式会社松本工務店 | 波賀の"隠れたヒーロー" | 未定（未連絡）。15秒CMの素材も同じ日に撮る案 |

- 放送の順番は、**南から北へ**（山崎・たつの → 一宮 → 波賀）を案にしています。ただし、どの回も前後の回を見ていなくても分かるように作ります。

## 2. どの回にも入れる「型」（番組ごとに完結するコーナー）

### コーナー①　加藤さんの「そもそもギモン」
- オープニングで、素朴な疑問担当の加藤さんが、その会社の仕事について**根っこの疑問**を1つフリップに書いて出す。
- 番組の中で答えを集め、エンディングで加藤さん自身が「答え」をフリップに書いてまとめる。
- 疑問の提示から答えまでが1本の中で完結するので、ほかの回を見ていなくても成立する。

| 回 | そもそもギモン（案） | 番組の中で集まる答え |
|---|---|---|
| 山弘 | 「工務店とハウスメーカーって、何がちがうの？」 | 木を選ぶところから大工、建てたあとまで、地元で一貫してやること |
| 川本石材 | 「お墓の石って、どこから来て、どうやってお墓になるの？」 | 原石 → 自社工場 → 字彫り → 据え付け。そして地元の神社や祭りにも |
| オアシス | 「ドライブインって、そもそも何？　なんで"オアシス"？」 | ただの食堂ではなく、道を行く人と地元の人の"たまり場" |
| 松本工務店 | 「土木って、何をつくってるの？」 | 道・橋・砂防ダム……ふだん目に入らない「暮らしの土台」 |

### コーナー②　「わたしのたからもの」
- 番組の終わり近くに、社長や店主に**「この仕事のたからもの」を1つ**見せてもらう。昔の写真・道具・お客さんからの手紙など。
- 会社の歴史と、その人の思いを、物を通して短く深く聞く。宣伝くさくならない締めくくりになる。
- 何を出すかは事前に先方と相談する（決めつけない）。

### 体験コーナー（1回に1つ）
| 回 | 体験 |
|---|---|
| 山弘 | この部屋、何度？（全館空調の温度当て。12月なので外との差がはっきり出る） |
| 川本石材 | 目かくし「石の種類当て」／字彫り |
| オアシス | 名物コロッケを丸めて揚げる |
| 松本工務店 | 重機かドローン |

### 毎回同じ流れ（30:00）

| ブロック | 尺 |
|---|---|
| アバン | 0:40 |
| タイトル | 0:10 |
| オープニング（「そもそもギモン」の提示） | 1:30 |

| わたしのたからもの | 1:30 |
| エンディング（「そもそもギモン」の答え合わせ） | 1:40 |

- 歩数カウンター（その回の歩数）は、各回の中だけで使います。
