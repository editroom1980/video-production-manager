## 1. 本数と並び

**30分の番組を、1社につき1本。全部で4本。** どの回も、その1本だけで成立するように作ります。

| 回（案） | 会社 | サブタイトル（案） | ロケ |
|---|---|---|---|
| 1 | 株式会社山弘（ヤマヒロ） | しそう杉の家で、冬なのに裸足になる | **12月1日（火）** たつの・龍野モデルハウス 9:00 → 宍粟・本社（オープニング） |
| 2 | 株式会社川本石材商会 | 160年、石を刻む家 | 未定（お客さんのお墓の場所が分かってから決める。10/28も候補） |
| 3 | お食事処 ドライブインオアシス | ドライブインに、歩いて行く | 未定（未連絡） |
| 4 | 株式会社松本工務店 | 波賀の"隠れたヒーロー" | 未定（未連絡）。15秒CMの素材も同じ日に撮る案 |

- 放送の順番は、**南から北へ**（山崎・たつの → 一宮 → 波賀）を案にしています。ただし、どの回も前後の回を見ていなくても分かるように作ります。

## 2. どの回にも入れる「型」（番組ごとに完結するコーナー）

> コーナー名はすべて**仮の名前**です。ほかの候補は下の「コーナー名の候補」にあります。

### コーナー①　「智子のハテナ散歩」（仮）
- オープニングで、素朴な疑問担当の加藤さんが、その会社の仕事について**根っこの疑問（今日のハテナ）**を1つフリップに書いて出す。
- 番組の中で答えを集め、エンディングで加藤さん自身が「答え」をフリップに書いてまとめる。
- 疑問の提示から答えまでが1本の中で完結するので、ほかの回を見ていなくても成立する。

| 回 | 今日のハテナ（案） | 番組の中で集まる答え |
|---|---|---|
| 山弘 | 「工務店とハウスメーカーって、何がちがうの？」 | 木を選ぶところから大工、建てたあとまで、地元で一貫してやること |
| 川本石材 | 「お墓の石って、どこから来て、どうやってお墓になるの？」 | 原石 → 自社工場 → 字彫り → 据え付け。そして地元の神社や祭りにも |
| オアシス | 「ドライブインって、そもそも何？　なんで"オアシス"？」 | ただの食堂ではなく、道を行く人と地元の人の"たまり場" |
| 松本工務店 | 「土木って、何をつくってるの？」 | 道・橋・砂防ダム……ふだん目に入らない「暮らしの土台」 |

### コーナー②　「これだけは、捨てられない」（仮）
- 番組の終わり近くに、社長や店主に**「これだけは捨てられない」という物を1つ**見せてもらう。昔の写真・道具・お客さんからの手紙など。
- 会社の歴史と、その人の思いを、物を通して短く深く聞く。宣伝くさくならない締めくくりになる。
- 何を出すかは事前に先方と相談する（決めつけない）。

### コーナー③　「本日の歩くやつ杯」（仮）
- 1回に1つ、3人がその会社の仕事に挑戦して勝ち負けを決める。その回の勝者には、手づくりの小さなトロフィー（または盾）を渡す。
- 勝ち負けは各回で決着するので、ほかの回とはつながらない。
- 当てる系（温度・石）は数字や正解数で、つくる系（コロッケ・重機）は社長や店主の判定で決める。

| 回 | 挑戦 |
|---|---|
| 山弘 | この部屋、何度？（全館空調の温度当て。12月なので外との差がはっきり出る） |
| 川本石材 | 目かくし「石の種類当て」／字彫り |
| オアシス | 名物コロッケを丸めて揚げる |
| 松本工務店 | 重機かドローン |

### 毎回同じ流れ（30:00）

| ブロック | 尺 |
|---|---|
| アバン | 0:40 |
| タイトル | 0:10 |
| オープニング（「今日のハテナ」の提示） | 1:30 |
| **本編（会社ごとに組む）** | **21:40** |
| これだけは、捨てられない | 1:30 |
| エンディング（「今日のハテナ」の答え合わせ・歩くやつ杯の表彰） | 1:40 |
| メッセージ | 0:30 |
| 会社の情報 | 0:30 |
| 支援者のお名前（クレジット） | 0:50 |
| アプリ・バナー広告の案内 | 0:30 |
| ED | 0:30 |
| **計** | **30:00** |

- 1本がまるごと1社の紹介になるので、「映像データお渡し」には番組をそのまま渡せます（切り出しの編集は要りません）。
- 歩数カウンター（その回の歩数）は、各回の中だけで使います。

### コーナー名の候補

**① 根っこの疑問を出して、番組の終わりに答える**

| 候補 | ねらい |
|---|---|
| **智子のハテナ散歩**（仮に採用） | 歩く番組らしく、「ハテナを持って歩き、答えを拾って帰る」。加藤さんの名前を冠したコーナーにする |
| それ、今さら聞いてもいいですか？ | 視聴者も聞けずにいた疑問を、加藤さんが代わりに聞く。タイトルを言うだけで笑いが取れる |
| 素朴すぎて、すみません | 加藤さんがフリップを出しながら頭を下げるのが決まりの形 |
| ハテナ持ち歩き中 | 画面の隅に「ハテナ持ち歩き中」と出し続け、答えが出たら消える |

**② 社長・店主に、物を1つ見せてもらう**

| 候補 | ねらい |
|---|---|
| **これだけは、捨てられない**（仮に採用） | 題名だけで「物語がある」と分かる。会社の歴史と人柄が出る |
| 社長のひきだし | 「引き出しを開ける」と「話を引き出す」をかける。店主の回は「店主のひきだし」 |
| 〇〇年分の、ひとつ | 創業からの年数を入れる（例：「160年分の、ひとつ」）。回ごとに数字が変わる |
| 物語のある一品 | わかりやすさ重視の案 |

**③ 3人の挑戦（体験）**

| 候補 | ねらい |
|---|---|
| **本日の歩くやつ杯**（仮に採用） | 番組名を使った小さな大会。毎回トロフィーを渡す決まりの形が作れる |
| 1日弟子入り | プロに教わる形。つくる系の体験に合うが、当てる系には合いにくい |
| 3人寄れば、プロに勝てるか | 3人で相談して挑む形。チームワークが見せ場 |
| 素人、プロの道具を借りる | 道具に注目する案。工場・厨房・重機に合う |
