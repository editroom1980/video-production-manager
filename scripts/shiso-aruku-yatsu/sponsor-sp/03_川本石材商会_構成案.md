## 1. この回の設計

### 伝えること（3本の柱）
| 柱 | 中身 | おもな場面 |
|---|---|---|
| ① 寄り添う | 大切な人を亡くした家族の思いを、お墓という形にする仕事 | S9・S10・S11・S12 |
| ② 地元への思い | 一宮で160年。伊和神社の太鼓橋をつくり、須行名の屋台とともに生きる | S3・S6・S13・S14 |
| ③ 石屋の技 | 石を見分ける目、レーザー刻印、現場の職人の技 | S7・S8・S10 |

### 1本を通す3つの「糸」
番組の中で投げて、番組の中で回収する。ほかの回とはつながらない。

| 糸 | 投げる | 回収する |
|---|---|---|
| **「石屋さんって、お墓だけ？」** | S3 加藤さんが伊和神社の前で聞く。鳥居は**入らずに通りすぎる**（「あとで来ます」） | S14 社長と鳥居をくぐり、**川本石材がつくった太鼓橋**を渡る |
| **「これ、何年もつんですか？」**（加藤さんの口ぐせ） | S8 刻印した石で1回目 | S10 お墓で2回目 → S14 太鼓橋で3回目。社長の答えがだんだん大きくなる。S16で3つを並べて笑いにする |
| **刻印した石** | S8 しそチャンNETのキャラクターを刻む →「この石、どうする？」 | S16 3人が石を持って**視聴者プレゼントを告知** |

### 気持ちの流れ
お店で笑う（S3〜S8）→ 刻む言葉で少しまじめに（S9）→ 安富の現場でしんみり（S10・S11）→ 温かい話（S12）→ お祭りで笑顔に戻る（S13）→ 太鼓橋で山場（S14）→ プレゼントで明るく終わる（S16）

## 2. アドリブのための道具箱（全員で共有）

### 基本の考え方
- 台詞は書かない。場面ごとに **ねらい／必ず押さえる／回し役／ネタ振り／幅** だけを決める。
- **「必ず押さえる」だけは撮り漏らさない。** あとは現場の空気を優先する。
- **「回し役」**は、その場面で話を前に進める人。ほかの2人は自由に動いてよい。
- 体験・試食・できあがりを見る瞬間は、**最初の1回をカメラが回った状態で**やる（やり直さない）。

### 合図（撮影の山内から出演者へ）
| 合図 | 意味 |
|---|---|
| 手をくるくる回す | 巻き（まとめに入って） |
| 両手を横に広げる | 伸ばし（もっと広げてよい） |
| 指で丸 | OK（次へ） |
| 手のひらを下に向けて上下 | 声を落として（墓地・境内） |

### 時間が押したら（削る順番）
1. S15 コーナー枠（作らない）
2. S12 建ててから（「きづな」とひと言だけにする）
3. S5 7代目（テロップとひと言だけにする）
4. S9 刻む言葉（社長の話1つだけにする）

**絶対に残す**：S8 刻印のできあがり／S10・S11 安富の現場／S14 太鼓橋／S16 プレゼントの告知

### 話が止まったときの予備ネタ（どの場面でも使える）
| 出演者 | 予備ネタ |
|---|---|
| 菊地さん | 宍粟・一宮の豆知識／カメラマンとして「この石、撮るならどの角度ですか？」 |
| 岡本さん | 社長に「いちばんうれしかった仕事は？」「いちばん大変だった仕事は？」 |
| 加藤さん | 「これ、何年もつんですか？」「重さは？」「どうやって運ぶんですか？」 |

### 社長のタイプで変える
- **話し好きだったら**：止めずに話してもらう。伸びた分は編集で選ぶ。回し役は、次の場面へのきっかけ（「じゃあ見せてもらっていいですか」）だけ出す。
- **口数が少なかったら**：質問攻めにしない。**物を手に取って説明してもらう**形にする（石・道具・写真）。仕事の話なら話せる人が多い。3人どうしの掛け合いで間をつなぐ。

### 雨だったら
| 場面 | 雨の日の案 |
|---|---|
| S3 国道を歩く | 傘をさして歩く（色違いの傘だと画になる）。大雨ならお店の軒先から始めて、鳥居の前を通るカットは車の中から撮る |
| S10 安富の現場 | 作業が中止になったら、お店で施工写真を見ながら社長の話を聞く（S11と合わせて2分） |
| S13 お祭りの話 | 歩く部分を短くし、車で移動。鳥居の前から撮る |
| S14 太鼓橋 | 濡れた石は光って画になる。**渡るときは滑らないよう注意**。大雨なら太鼓橋は全景だけ撮り、インタビューは屋根の下で |

### 撮る順番の注意（出演者は必ず読む）
- 安富の現場（S10・S11）は**午前に撮る**が、番組では**お店の場面のあと**に置く。
- 3人と社長が実際に初めて会うのは安富になる。**午前は「はじめまして」の場面を撮らない。** どちらの順番で見ても不自然にならない話し方にする（「さっきお店で〜」とは言わない）。
- 午後の「お店の前で出会う」場面（S4）は2回目に会う形になる。出会いは芝居で驚くより、社長の人柄とお店の様子（看板・石の製品・フクロウ）で見せる。
- 加藤さんの「何年もつんですか？」の2回目（S10）は午前に撮るが、番組では1回目（S8）のあとに来る。**午前も、初めて聞くような言い方は避け、「これは何年もつんですか？」と普通に聞く**（編集で並べたときに口ぐせに見える）。
- 午前と午後で、3人の服装を変えない。

### 笑いとマナー
- お墓は、悲しい思い出につながる人もいる題材。**お墓そのものではなく、3人のやりとりや石の不思議で笑う。** お店や神社では遠慮せず、いつもの3人でよい。
- 安富の現場でお客様の話を聞くときは、**笑いを取らない**。岡本さんが聞き手の中心、2人は聞き役。
- 墓地では、ほかのご家族のお墓の名前を映さない。大きな声で騒がない。
- 国道29号の歩道を歩くときは、運転役の方に車で先回りしてもらい、安全を見てもらう。

### S7　石当てクイズ（3種類）　2:40
- **撮影**：午後／お店　**回し役**：菊地（出題・答え合わせは社長）
- **ねらい**：石にはいろいろな種類があることを、遊びで見せる。

  - 最後に社長にも挑戦してもらう（プロの技）
- **やり方**：3人が目をつぶって（目かくしで）触る → 1人ずつ答える → 社長が正解発表 → 社長も挑戦
- **ごほうび**：いちばん当てた人が、S8の刻印の「スタート係」（機械のボタンを押せるかは当日確認。無理なら「最初にできあがりを見る係」）
- **ネタ振り**
  - 加藤：触った感想が独特（「この子はやさしい感じ」）
  - 菊地：目を開けて色で勝負しようとする（ずるい、とツッコまれる）
  - 岡本：アナウンサーらしく、手ざわりを言葉にする
- **幅**
  - もしも全員正解のとき：社長に**難問を1つ追加**してもらう
  - もしも全員不正解のとき：社長のお手本で「なぜ分かるのか」を聞く（ここがいちばんの見どころになる）
  - もしも社長が出題を照れるとき：菊地さんが司会、社長は答え合わせだけ
  - 転がる先：石によって値段も変わる → お客様の予算に合わせて石を選ぶ話（寄り添いの入口）

### S10　安富町のお墓の工事現場　3:00
- **撮影**：**午前** 11:00／姫路市安富町の墓地　**回し役**：菊地
- **ねらい**：今の川本石材の仕事の中心である現場で、職人の技と、ご家族の思いを形にする仕事を見せる。
