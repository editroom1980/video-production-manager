# 第1部　ご提案（先方にお見せする用）

## 宍粟を歩くやつ スペシャル「株式会社松本工務店」
### 〜波賀の"隠れたヒーロー"に会いに行く〜

このたびは、しそチャンNETのクラウドファンディングにご支援いただき、ありがとうございました。
御社を紹介する30分の特別番組と、15秒CMを制作いたします。番組の内容について、いくつかアイデアをお持ちしました。ぜひご意見をお聞かせください。

## 番組の柱

御社のコピー**「暮らしを支える、隠れたヒーロー。」**を、番組の柱にしたいと考えています。
毎日あたりまえに使っている道や学校。それを誰がつくり、守っているのか。出演者3人が波賀を歩き、御社の仕事と、働く皆さんの姿を紹介します。

**出演**：菊地周星（しそう観光大使・カメラマン）／岡本陽子（アナウンサー）／加藤智子（健康体操トレーナー・森林セラピスト）

## アイデア一覧

### ★ アイデア1　中学校の「エレベーター」ができるまで（番組の中心に）
御社が手がけている、中学校のエレベーター工事を番組の中心にします。
<!-- 社内メモ：学校名（波賀中学校か千種中学校か）は打ち合わせで確かめてから、ここに書き入れる -->

- **見どころ**
  - 学校にエレベーターができると、何が変わるのか。けがをした生徒、車いすの方、学校が避難所になったときのお年寄りなど、**誰のための工事なのか**を伝えます。
  - **授業をしている学校の中での工事**です。生徒の安全や授業の妨げにならないよう、どんな工夫をしているかを紹介します（音・時間・通り道の工夫など）。
  - 完成予想図と今の現場を見比べて、完成した姿を想像します。
- **出演者の動き（例）**
  - 3人がヘルメットをかぶって、安全の説明を受けてから現場へ。
  - 現場の責任者の方に、工事の進み具合と苦労を伺います。
- **ご相談したいこと**
  - 学校と市（発注元）の撮影の許可
  - 生徒が映らない時間・場所での撮影、または映る場合の扱い
  - 校長先生か先生から、ひとこといただけるか

### アイデア2　「母校をつくる」社員さん
- 社員さんの中に**その中学校の卒業生**がいらっしゃれば、その方に現場を案内していただきます。
- 「自分が通った学校を、自分の手で良くする」思いを伺います。中学時代の思い出話で、出演者との掛け合いも生まれます。

### アイデア3　朝礼にまぜていただく
- 朝礼に出演者3人が参加します。
- 健康体操トレーナーの加藤が、皆さんと一緒に体操をします（腰を守る体操などをご紹介）。
- 会社の朝の空気と、社員の皆さんの顔をお伝えします。

### アイデア4　波賀を歩いて「これも松本工務店」探し
- 本社の近くを歩きながら、御社が手がけた道路・橋・砂防ダム・擁壁などを、社員の方の案内で見つけていきます。
- ふだんは気づかない「暮らしの土台」が、実は身近にたくさんあることを伝えます。
- 林野庁長官賞を受賞された**「戸倉東山渓間工事」**（令和5年度 治山・林道工事コンクール）も、ご紹介できればと考えています。

### アイデア5　重機かドローンに挑戦
- 出演者が、社員の方に教わりながら重機（敷地の中など安全な場所で）か、ドローンに挑戦します。
- プロのお手本との差で、技術のすごさを伝えます。
- 新しい技術（ドローン講習など）に取り組んでいることもご紹介します。

### アイデア6　若手社員さんに聞く
- 入社して間もない社員の方に、この仕事を選んだ理由とやりがいを伺います。
- 採用にも役立つ内容にします。

### アイデア7　「困った時の松本工務店」
- 豪雨や地震のとき、すぐ現場に駆けつける御社の姿勢を、社長に伺います。
- 熊本地震のとき、個人のお宅の修繕を引き受けられたお話もお聞きしたいです。

### アイデア8　明治24年からの歩み
- 大工だった曽祖父さまが波賀町で創業されてから、4代目の社長まで。
- 昔の写真があれば、ぜひお借りしたいです。

### アイデア9　波賀の町のために
- 社長が会長を務める「波賀元気づくりネットワーク協議会」で、森林鉄道を復活させたこと。
- はがてらす図書室への児童書の寄贈など、町への思い。
- ※会社のお仕事と、協議会の活動は、分けてご紹介します。

## 15秒CMの案

番組と同じ日に、CMの素材も撮影させていただければと考えています。

| 案 | テーマ | 内容 |
|---|---|---|
| A | 隠れたヒーロー | 道の下、橋の裏など、ふだん見えない所で働く社員の皆さん → 「暮らしを支える、隠れたヒーロー。」 |
| B | 明治24年から、波賀とともに | 昔の写真 → 今の現場 → 「波賀の松工から、日本の松工へ」 |
| C | 仲間、募集中 | 若手社員がドローンや重機を操る姿 → 採用情報 |
| **D（新）** | **学校をつくる** | 中学校のエレベーター工事 → 完成した学校で笑う子どもたちのイメージ → 「子どもたちの毎日を、支えています。」 |

- CMの目的（会社を知っていただく／人を採用する）によって、おすすめの案が変わります。
- D案は、完成したエレベーターの映像が撮れるかどうかで内容が変わります。
