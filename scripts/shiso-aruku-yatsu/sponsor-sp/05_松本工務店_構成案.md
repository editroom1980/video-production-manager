### この回の気をつけどころ
- 工事の現場では、**安全がいちばん**。ヘルメット・安全靴・立ち入ってよい範囲を、先方の指示に従う。
- 公共工事の現場は、発注元（国・県・市など）の撮影許可が要ることがある【要確認】。
- 松本工務店は採用のイベントにも出ている。この回は**若い人に「この仕事、かっこいい」と思ってもらえる**作りも意識する（若手社員に出てもらう）。

### S1　アバン　0:40
- **使う絵**（編集で選ぶ）：朝礼で体操する社員さんと加藤さん／ヘルメット姿の3人／重機を動かす真剣な顔／森林鉄道が走り出す／社長の印象的なひとこと

### S3　オープニング　1:30
- **場所**：本社の前（波賀町上野）、朝
- **ねらい**：特別編であること、今日の会社。
- **必ず押さえる**
  - クラウドファンディングで応援してくださった会社を訪ねる特別編であること
  - 「株式会社松本工務店／宍粟市波賀町」
  - バナーのコピー「暮らしを支える、隠れたヒーロー。」
- **ネタ振り**
  - 菊地さん：「今日は、ヒーローに会いに行きます」
  - 加藤さん：「ヒーロー!?　……工務店ですよね？」
  - 加藤さん（素朴な疑問）：「土木って、何をつくってるんですか？」
  - 岡本さん：創業が明治24年だと紹介して、2人を驚かせる。

### S4　朝礼にまぜてもらう　2:00
- **ねらい**：会社の朝の空気と、社員さんたちの顔。加藤さんの本職が生きる場面。
- **必ず押さえる**
  - 朝礼の全景（社員さんがそろう絵）
  - 社長が出迎える。テロップ「代表取締役 松本貞人さん」
  - 3人がヘルメットを受け取る（バナーと同じ、黄色に「松本工務店」の字）
- **ネタ振り**
  - 加藤さん（健康体操トレーナー）：朝礼の体操に入れてもらう → 体操のプロとして、社員さんに腰を守る体操を1つ教える。
  - 菊地さん：ヘルメット姿の3人を見て「ヒーローっぽい」。
  - 岡本さん：朝礼でひとこと挨拶をさせてもらう。
- **転がりそうな方向**：社員さんの反応（照れる・本気でやる）がそのまま笑いになる。
- **備考**：朝礼に入ってよいか、時間は何時か【要確認】。体操の時間が無い会社なら、加藤さんが体操を提案する形にする。

### S5　4代目と明治24年　1:40
- **ねらい**：会社の歴史と社長の人柄。
- **必ず押さえる**
  - 明治24年（1891年）、大工だった曽祖父が波賀町で創業したこと。今の社長で4代目
  - 土木（道路・橋・砂防ダム・国有林・水力発電所）と建築（保育園・温水プール・商業施設など）
  - 「波賀の松工」から「日本の松工」へ
- **ネタ振り**
  - 菊地さん：曽祖父の大工さんの話。昔の写真はあるか【要確認】。
  - 加藤さん：「土木と建築って、何が違うんですか？」
- **転がりそうな方向**：子どものころ、会社や現場をどう見ていたか。

### S6　波賀を歩いて「隠れたヒーロー」探し　3:00
- **ねらい**：**この回ならではの「歩く」場面。** ふだんは目に入らない、松本工務店の仕事を、町を歩きながら見つける。
- **必ず押さえる**
  - 社長か社員さんの案内で、本社の近くを歩く
  - 松本工務店が手がけた道路・橋・擁壁・砂防ダム・側溝など（**歩いて行ける範囲に何があるか、事前に先方に聞く【要確認】**）
  - 見つけるたびに「これも松本工務店」とテロップを出す
- **ネタ振り**
  - 3人：「これもですか？」「これも？」と、次々に見つける。最後には何でも松本工務店に見えてくる。
  - 加藤さん：足元の側溝や、道の下の見えない部分に興味を持つ。
  - 菊地さん（カメラマン）：ふだん気づかない構造物を、かっこよく撮る。
  - 岡本さん：「この道、毎日通ってるのに知らなかった」。
- **転がりそうな方向**：「この道がなかったら、どうなるか」→ 暮らしを支える仕事であることへ。

### S7　いま動いている現場へ　3:00
- **場所**：撮影の時に動いている工事の現場（道路・橋・砂防ダム・治山など）【どこにするか要確認】
- **ねらい**：「隠れたヒーロー」の仕事の現場を見せる。
- **必ず押さえる**
  - 現場の全景（できれば**ドローンで上から**）
  - 安全の説明を受ける3人
  - 作業する社員さんの手元・重機
  - 現場の責任者の話（何をつくっているか、いつ完成するか）
- **ネタ振り**
  - 加藤さん：「この道路って、何年もつんですか？」
  - 菊地さん：重機の大きさを、人と並べて見せる。
  - 岡本さん：現場の責任者に、この仕事のやりがいを聞く。
- **転がりそうな方向**：道路の寿命の話 → だから点検や補修が欠かせない → 災害のときの話（S10）へ。
- **備考**：社員さんのお顔を出してよいか、その場で確かめる。

### S8　体験：重機かドローン　3:00
- **ねらい**：仕事の面白さを、3人が挑戦して見せる。
- **案A　重機**：敷地の中か資材置き場で、小さな重機（ミニショベル）を動かす。社員さんが横について教える。
  - 例：バケットでボールをつかむ、砂を決まった場所に移す、などの課題
- **案B　ドローン**：社長が力を入れているドローン講習に合わせて、社員さんがドローンを飛ばす。
  - 例：菊地さん（カメラマン）がドローンのカメラ映像を見て、3人を上から撮る
- **必ず押さえる**
  - 体験する3人と、教える社員さんの両方
  - 土木の仕事にも、ドローンなど新しい技術が入っていること
- **ネタ振り**
  - 3人：同じ課題に順番に挑戦する。うまくいかない人が出るほど面白い。
  - 社員さん：お手本を見せる → 3人がプロの腕に驚く。
- **備考**：どちらの案にするか、安全面から先方と【要相談】。資格がない人が重機を動かしてよい場所か確かめる。

### S10　「困った時の松本工務店」　1:40
- **ねらい**：災害のときにすぐ駆けつける会社であることを、社長の言葉で伝える。
- **必ず押さえる**

  - 地元の人から「困った時の松本工務店」と言われていること

- **ネタ振り**

- **備考**：災害のときの写真があれば借りる【要確認】。

### S11　森林鉄道を走らせた社長　4:00
- **場所**：フォレストステーション波賀【運行日・撮影許可を要確認】
- **ねらい**：**この回の山場。** 建設会社の社長が、町の宝をよみがえらせた話。
- **必ず押さえる**
  - 機関車と線路の全景
  - 社長と3人が乗る → 走り出す（車両の前・横・乗っている人の顔）
  - 大正から昭和にかけて、波賀の山から木を運んだ森林鉄道。最も長いときには総延長40km以上。1968年に廃止
  - 2024年10月、地元の人たちの手で、1周678mの線路がよみがえったこと
  - 社長が「波賀元気づくりネットワーク協議会」の会長であること
  - 昔の森林鉄道の写真（協議会か市から借りる【要確認】）
  - **協議会としての活動と、会社としての仕事を分けて伝える**（会社がどこまで関わったか【要確認】）
- **ネタ振り**
  - 菊地さん：「どうして、森林鉄道を復活させようと思ったんですか？」
  - 加藤さん（森林セラピスト）：森の中を走る鉄道に乗った感想。
  - 岡本さん：「本業の技術が、町の宝を掘り起こしたんですね」
  - 3人：線路の整備を手伝う体験ができないか【要相談】（ボランティアの整備の話があるため）。
- **転がりそうな方向**：昔、森林鉄道が走っていたころの波賀の話 → 町の魅力を伝えたいという社長の思い → 軽トラ市など、ほかの町おこしの話。
- **備考**：
  - **個人向けリターンの中谷信行様**（ロケ同行＋コース指定。希望は「はがね駅周回コース」か「中音水遺構」）を、この場面に組み込む案がある。**中谷様の了解が前提**。ふだんの回で行うほうがよいかも含めて【要相談】。
  - 駅の名前（「はがね駅」）・運行日・料金・2026年の状況は【要確認】。

### S12　15秒CMの撮影と、お披露目　1:30
- **ねらい**：20万円コースの15秒CMを、番組の中でお披露目する。CMの価値を上げる。
- **必ず押さえる**
  - CMの撮影のようす（社員さんがカメラの前で並ぶ、など）を少しだけ
  - **CMの本編（15秒）を、番組の中で初公開**
  - 見終わった3人の反応
- **ネタ振り**
  - 菊地さん（カメラマン）：CMを撮る側として、撮影の裏側を少し話す。
  - 3人：CMに3人が少しだけ映る案もある（先方と相談）。
- **備考**：
  - CMを番組の中で流してよいか、先方の了解を得る。
  - CMの完成が放送に間に合うか確かめる。間に合わなければ、撮影のようすだけにする。
