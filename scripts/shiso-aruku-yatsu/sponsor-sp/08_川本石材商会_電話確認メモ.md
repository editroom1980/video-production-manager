# 川本石材商会　電話確認メモ

- 相手：川本こず江 様（窓口）
- 所要時間：10分ほど
- 答えは「回答」の欄に書きこむ。

---

## はじめに（ひとこと）
「しそチャンNETの【名前】です。ご支援のお礼の特別番組の件で、撮影できることを10分ほど伺ってもよろしいでしょうか。いただいたお答えで、番組の内容を決めます。できないことがあっても、まったく問題ありません。」

## 聞くこと（上から順に）

| # | 質問 | 回答 |
|---|---|---|
| 1 | **ロケの日**：【候補日】のうち、ご都合のよい日と時間は？ 社長と職人さんがいらっしゃる時間も教えてください。 | |
| 2 | **お客様のお墓**：場所はどこですか？ 作業を撮ってよいですか？ お客様にお話を伺えますか？ お名前やお顔は出してよいですか？ | |
| 3 | **工場**：嵯峨山工場で、石を切る・磨く・字を彫るところを撮れますか？ | |
| 4 | **字彫りの体験**：出演者3人が、小さな石に1文字ずつ彫る体験はできますか？ | |
| 5 | **石当てクイズ**：石の見本を3〜5種類ご用意いただけますか？（目かくしで触って当てる） | |
| 6 | **伊和神社の太鼓橋**：社長と一緒に渡って、つくったときのお話を伺えますか？ 神社の撮影の許可は、御社からご紹介いただけますか？ | |
| 7 | **秋祭り**：祭りの映像を社長と一緒に見ながら、須行名の屋台のお話を伺えますか？ | |
| 8 | **こず江様のご出演**：お客様のご相談を受けるときに大切にしていることを、伺えますか？ | |
| 9 | **お借りしたいもの**：太鼓橋や昔の写真、お墓に刻んだ言葉の例（お名前が分からない形で）はありますか？ | |
| 10 | **番組で出す・出さない**：価格を出してよいですか？ 触れてほしくないことはありますか？ | |
