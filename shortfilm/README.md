# 撮影帳（短編映画の撮影と記録）

台本・香盤表・カット表・そのほかの資料を読み込んで、当日の **撮影チェックシート** と、編集に渡す **スクリプト表** を作る HTML アプリです。サーバーは要らず、データは使っている端末の中に保存されます。

## 流れ

1. **資料**：台本・香盤表・カット表を入れる（まとめて選べます）。読み取った結果を確かめてから取り込みます。
2. **香盤**：シーン・撮影日・開始時刻・出演・小道具・カット割りを直す、足す。撮影日ごとの並べ替え、人物ごとの出番表も見られます。
3. **撮影**：当日はシーンごとに出演・小道具・衣装の準備を確かめ、「記録する」でテイクを付けます。スタート→カットで長さを計り、OK／KEEP／NG を押すと1テイク記録。クリップ名・音声ファイル名は自動で1つずつ進みます。
4. **記録**：シーン・カット・テイクごとの一覧と、OK の無い「撮り残し」。
5. **出力**：撮影チェックシート・スクリプト表・香盤表を、印刷（PDF 保存）・Excel 用 CSV・文字で送る、のどれかで出します。作品データの保存と読み込みで、別の端末へ移せます。

## 読める資料

| 形式 | 中身 |
| --- | --- |
| テキスト（.txt など）・Word（.docx）・PDF | 台本。「○公園（昼）」「S#1」「#1」「シーン1」「1　公園（夜・外）」「1　現在の昼間　温泉階段」「INT. 〜 - NIGHT」などの柱と、「名前「台詞」」を読み取ります。「同」「同・玄関」は前のシーンの場所から補います。縦書きの PDF（1枚に何ページも並べたものも）、「高峰Ｎ」のようなナレーション、「字幕」「※写真」「※ＣＧ映像」「ＳＥ：」にも対応 |
| Excel（.xlsx / .xls）・CSV（UTF-8 / Shift_JIS）・PDF の表 | 香盤表・カット表。用紙を横に回した PDF の表、見出しのない時刻の列、「11/05(木)　13時00分　現地集合」のような日の区切り、表の下の【準備物】にも対応。見出しの行（シーン・場所・ロケ地・昼夜・出演・小道具・衣装・備考・撮影日・時間・カットなど）を探して読み取ります。人物ごとに○を付ける形式、結合したセル、「4・5」「3〜5」のような複数シーンにも対応 |
| その他 | 資料として保存して、あとで見られます。持ち物・機材リストは1行ずつ当日のチェックに入れられます。PDF はページを画像でも残せるので、写真や地図の入った資料はシーンの「参考画像」に付けられます |

読み取りがずれたときは、取り込む前に「列の読み方を確かめる・直す」で列の割り当てを変えられます。紙をスキャンした PDF（文字の入っていないもの）は読めません。

## シーンに付けられるもの

- **演出メモ**：撮影の画面と記録の画面に出ます
- **参考画像**：古写真と同じ構図で撮るための見本、立ち位置の図など。撮影中にタップで拡大できます
- **同じシーンの別の撮影予定**：1つのシーンを別の日・別の場所に分けて撮るとき（香盤表に同じシーンが2回出てくると自動で作られます）
- **撮影しないシーン**：資料映像や写真・ＣＧだけで作るシーン。撮り残しの数えに入りません
- **編集素材**：台本の ※写真・ＣＧ・動画、字幕、ナレーション、唄、ＳＥ を自動で拾い、「出力」の **編集素材リスト** にまとめます

作品データ（画像も含む）は「出力」の「作品データを保存」で1つのファイルになり、ほかの端末で「作品データを読み込む」と同じ状態になります。

## ファイル

- `index.html`：アプリ本体
- `sw.js`・`manifest.json`・アイコン：ホーム画面に追加して、電波のない現場でも使うためのもの
- `lib/`：ファイル読み取り用の部品（SheetJS Community Edition・mammoth.js・PDF.js）と使用許諾
