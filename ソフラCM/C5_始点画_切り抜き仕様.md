# 訂正（重要）— 膝の位置を誤って測っていた

**上に書いた「素足の上端＝膝」は誤り。切り抜きすぎて腰上になった。**

## 何を間違えたか

1. 彼女は**パンツスーツ**で、素足が出ていない。膝に肌色は無い。
2. 実写のサーバールーム背景は**床が暖色**で、これが肌色判定に引っかかった。
   → 画面下部の「肌」は脚ではなく**床**。それを膝と読んだ。
3. その誤った膝（78.3%）を基準に下端75%で切ったので、実際には**腰〜腿**で切れた。

## 正しい読み方

肌色で脚を探すのは、この背景では使えない。**顔の帯だけが信用できる。**

`f8f1fe94` の顔（生え際〜顎）＝画面の 17.1%〜30.2% ＝ **13.1%**。
顔の実寸を0.16mとすると画面の縦の実寸は **約1.22m**。
頭頂1.60mが12.8%の位置 → 上端1.76m、**下端 約0.54m ＝ 膝のすぐ上**。

**つまり4kの元画は、切り抜かない状態でほぼ「膝上」になっていた。**
切り抜きは不要。元画をそのまま使う。

# soul_2（Soul 2.0）は指示が通らない — 使用不可

キャラクター **「Polished Ambition」**（`soul_id: 26e2238a-724e-46eb-93d0-a6a19f061978`、ready）が存在する。
1枚 **0.12**（`nano_banana_pro` の2.00に対し約1/17）と安いが、**構図の指示が一切通らない。**

## 何が起きるか

`soul_2` はサーバー側で `enhance_prompt: true` が固定され、**送ったプロンプトを破棄して別の文章に書き換える。**

`enhance_prompt: false` を送っても API が拒否する：

```
params.enhance_prompt: requested false -> used "omitted"
reason: "Higgsfield Soul 2.0 does not support this parameter"
```

`style_strength` も同様に omitted される。

実際に2回撃って、2回とも完成ジョブの params が「会議室に5人、SOFLAと書かれた本、街並みの見える窓」という
**こちらが一言も書いていない文章**に差し替わっていた（jobs `67d4c83e` / `2dcc7d4f`）。

**結論：画角・人数・配置・場所を指定する必要があるカットに soul_2 は使えない。**
安さに釣られて使わないこと。指定が要らない当てもの用途以外は `nano_banana_pro` を使う。

なお soul_2 の出力は **2048×1152**。H3 の 2560×1440 に足りない。
